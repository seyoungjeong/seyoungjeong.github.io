# Tech Blog Section Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a `/posts/` tech blog to alpentalsystems.com with Korean posts, an English summary box per post, and links from the landing page.

**Architecture:** Plain Hugo templates, no theme. Header and footer move into partials shared by the home page, the posts list, and post pages. A `post-list.html` partial renders post items for both the list page and the home "recent posts" section.

**Tech Stack:** Hugo extended (local v0.163.0), Go templates, plain CSS.

**Spec:** `docs/superpowers/specs/2026-09-25-tech-blog-design.md`

## Global Constraints

- Do not change existing landing page copy.
- Taxonomies stay disabled (`disableKinds = ["taxonomy", "term"]`).
- Front matter is YAML. Post fields: `title`, `date`, `description`, `summary_en` (folded `>` scalar), `repo`, `draft`.
- CSS uses existing variables in `static/css/style.css` (`--color-*`); new rules go above the `@media (max-width: 640px)` block.
- The home "기술 블로그" section and nav link render only when at least one published post exists.
- `hugo --gc --minify` must finish with no `WARN` or `ERROR` lines.
- Commit messages: conventional commits, no Claude attribution lines. Do not push.

## Test approach

There is no test suite. Tests are shell assertions against built HTML.
Builds used for assertions skip `--minify` so attribute quotes stay intact.
